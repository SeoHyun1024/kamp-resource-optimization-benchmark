# KAMP Resource Optimization

## 실행 방법

### 1. 가상환경 생성

```bash
python -m venv .venv
```

### 2. 가상환경 활성화

Mac / Linux

```bash
source .venv/bin/activate
```

Windows

```bash
.venv\Scripts\activate
```

### 3. 패키지 설치

```bash
pip install -r requirements.txt
```

### 4. VS Code에서 실행

1. VS Code에서 프로젝트 폴더 열기
2. Python, Jupyter Extension 설치
3. `.ipynb` 파일 열기
4. 우측 상단 `Select Kernel` 클릭
5. `.venv` 환경 선택
6. 셀 순서대로 실행
